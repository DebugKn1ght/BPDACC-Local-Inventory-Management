================================================================================
BPDACC LOCAL INVENTORY MANAGEMENT - SETUP GUIDE
================================================================================

This system uses Next.js, Prisma, and MySQL (via XAMPP).

--------------------------------------------------------------------------------
[1] PREREQUISITES INSTALLATION
--------------------------------------------------------------------------------

1. INSTALL NODE.JS
   - Download Node.js (v18 or higher recommended) from: https://nodejs.org/
   - Run the installer with default settings

2. INSTALL XAMPP
   - Download XAMPP from: https://www.apachefriends.org/
   - Run the installer (default settings are fine).
   - After installation, open the XAMPP Control Panel.
   - Click "Start" next to MySQL to start the MySQL server.
   - (Tip: You can also start Apache if you want to use phpMyAdmin
     for visual database management at http://localhost/phpmyadmin)

3. CREATE THE DATABASE
   Option A - Using phpMyAdmin (recommended for beginners):
   - Start both Apache and MySQL in XAMPP Control Panel.
   - Open your browser and go to: http://localhost/phpmyadmin
   - Click "New" in the left sidebar.
   - Enter "bpdacc_inventory" as the database name.
   - Click "Create".

   Option B - Using MySQL Command Line:
   - In XAMPP Control Panel, click "Shell" to open a terminal.
   - Type: mysql -u root
   - Then run: CREATE DATABASE bpdacc_inventory;
   - Type: exit

--------------------------------------------------------------------------------
[2] SYSTEM CONFIGURATION
--------------------------------------------------------------------------------

1. SET UP ENVIRONMENT VARIABLES
   - Create a new file in this folder named EXACTLY `.env` (with the dot at the beginning).
   - Open the `.env` file in Notepad.
   - Add this line (XAMPP uses root with no password by default):
     DATABASE_URL="mysql://root:@localhost:3306/bpdacc_inventory"

   - If you set a custom password for root, include it after the colon:
     DATABASE_URL="mysql://root:your_password@localhost:3306/bpdacc_inventory"

2. INSTALL PROJECT DEPENDENCIES
   - Open Command Prompt or PowerShell in this folder.
   - Run the following command:
     npm install

3. PUSH THE DATABASE SCHEMA
   - Still in Command Prompt/PowerShell, run this command to build the tables:
     npm run db:push
   - This command reads `prisma/schema.prisma` and creates all necessary tables in MySQL.

--------------------------------------------------------------------------------
[3] STARTING THE APPLICATION
--------------------------------------------------------------------------------

1. MAKE SURE MYSQL IS RUNNING
   - Open XAMPP Control Panel and ensure MySQL shows "Running" (green).

2. START THE DEVELOPMENT SERVER
   Using the Quick Batch File (Recommended):
   - Double-click `start_system.bat` located in the project root folder.
   - A command window will open, navigate to the project directory automatically,
     and start the Next.js server.
   - Keep this terminal window open (or minimized) while using the application.

   - Creating a Desktop Shortcut (Optional for Easy Access):
     1. Right-click `start_system.bat` in the project folder.
     2. Select "Show more options" (on Windows 11) > "Send to" > "Desktop (create shortcut)".
     3. You can now launch the application anytime directly from your Desktop!

   - Auto-Starting with Windows (Optional):
     1. Press `Win + R`, type `shell:startup`, and press Enter.
     2. Copy and paste the desktop shortcut of `start_system.bat` into this Startup folder.
     3. The server will now start automatically whenever Windows boots up.


3. Wait until you see "Ready in ... ms"
4. Open your web browser and go to:
     http://localhost:0911

(Note: You can view and edit your database contents visually anytime by
 running `npm run db:studio` in a new terminal window, or by visiting
 http://localhost/phpmyadmin in your browser while XAMPP's Apache is running!)

5. Users will open the program through the browser then input the IP Address (ex.192.168.<IPv4 address>:0911), replace IPv4 with actual ip address of the host computer. 

--------------------------------------------------------------------------------
[4] TROUBLESHOOTING
--------------------------------------------------------------------------------

- "Can't connect to MySQL server"
  -> Make sure MySQL is running in XAMPP Control Panel.
  -> Check that port 3306 is not blocked by another application.

- "Access denied for user 'root'"
  -> XAMPP default is root with NO password. If you set a password,
     update the .env file accordingly.

- Port conflict (another MySQL instance on 3306)
  -> Stop any standalone MySQL services: Open Services (services.msc),
     find "MySQL", and stop it.
  -> Or change XAMPP's MySQL port in XAMPP Control Panel > Config.
